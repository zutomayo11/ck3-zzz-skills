# 原版人物年龄与特质形变

适用于启用本机 3D 包后，普通原版人物发生年龄／体型／面部形变异常。关键词：儿童成年身体、boy/girl、minimum_age、maximum_age、morph_genes、gene_hunchbacked、beauty_bad_1、portrait extremity、文件排序、ethnicity。

## 先区分数据与显示

保持 CK3 版本、前置、角色包及场景一致，对比问题包关闭／单独开启／已知正常包；完全重启后核实实际加载目录和版本。历史 ID 用于跨存档识别，内部角色 ID 不保证固定。检查历史定义与存档中的年龄、特质、ethnicity 及原版 DNA 段，不因外观异常就认定遗传数据已被改写。

普通人物保留正确年龄和特质却显示异常时，优先核对私有画像注册及全局覆盖。私有名称、没有直接覆盖 human 定义，都不足以排除引擎加载副作用。保留对照日志和失败候选；不先改原版 mesh、骨架、Shader、特质或人物 DNA。

## 儿童变成人：配套处理私有类型与 morph

本机 CK3 1.20／Anime Core 组合中，历史社区参考两包仅按性别声明两个私有类型，无年龄门槛，并使用空私有 morph 容器。作者注释记录私有儿童类型曾使原版儿童显示成年身体；Fix 采用配套方案后，0.1.6 获用户确认儿童恢复。

对使用同类固定 3D 模型、且复现该症状的私有画像组，核对并一起处理：

1. 移除私有 `boy/girl` 类型及引用，私有 `male/female` 仅按性别选择，去掉 `minimum_age`／`maximum_age`。原版 human 和 Anime Core 的年龄类型不改。
2. 移除为注册私有组合成的 neutral／占位 morph gene，保留每个私有组的空容器。例如：

   ```text
   morph_genes = { portrait_group = p2fix_ellen_3d }
   ```

3. 同步清除占位 morph gene 在 ethnicity、customization rules 等处的引用，检查动画类型映射和所有私有儿童别名无残留。保留服装和道具 accessory genes；不要把它们与占位 morph gene 一起删除。
4. 从生成器定向刷新候选，用哈希确认模型、蒙皮、动画、贴图未变，再分别做启动和儿童画面对照。

**失败组合**：只删除私有儿童／年龄类型、仍保留 neutral gene 的 Fix 候选加载崩溃；再补调色板或仅改类型文件排序仍失败。两类＋空 morph 容器＋删除配套引用才完成启动及后续儿童验收。不能将这些失败候选覆盖到已验收版本，也不能把这一方案推广为删除其他包所有真实 morph genes 的通用规则。

儿童样例：佐伊·杜卡斯，历史 ID `9809`，样例存档内部 ID `40580`；曾在新档和旧档均异常。0.1.6 的验收范围是普通儿童恢复，不包含 DNA 隔离或所有游戏入口。

## 驼背／其貌不扬消失：核对注册排序

驼背涉及原版 `gene_hunchbacked` special gene；其貌不扬 `beauty_bad_1` 通过 portrait extremity 参数影响形变。两种外观同时消失时，检查共同的基因／肖像类型注册，而不是为单一历史人物添加外观补丁。

已验收的 Fix 0.1.7 在上述儿童修复基础上，只调整文件名：

| 路径 | 修改前 | 修改后 |
|---|---|---|
| `common/genes/` | 六份 `p2fix_*.txt` | `41_p2fix_*.txt` |
| `common/portrait_types/` | `p2fix_portrait_types.txt` | `10_p2fix_portrait_types.txt` |

这些名称在对应目录内排序先于 Anime Core 的 `anime_genes_morph.txt` 和 `anime_portrait_types.txt`，该轮已与正常参考包的相对排序对照。七份文件内容逐字节不变。用户于 2026-10-04 确认 Gottfried（历史 `20248`，样例内部 `36149`）的驼背与其貌不扬均恢复，支持此排序修正有效；具体引擎机制未证实。

在相同架构下保留这一排序约束。其他包先核对实际文件和依赖再做单变量候选；`10_`／`41_` 是已验证命名方案，不是已证明的引擎保留数字。改生成器并移除候选中的旧文件，避免新旧文件重复定义。这里是包内数据库文件排序，不等于调整启动器 Mod 顺序；不要据此擅自更改播放集。

## 回归与证据边界

- 核对最终输出中的上游同路径覆盖、基因命名空间、肖像类型、特质、DNA 定义及原版实体重名；普通动作分支应保留上游行为。静态无冲突不等于运行时形变正常。
- 记录受保护资源哈希，验证只改预定文本。为类型数量、无私有年龄门槛／占位 gene 残留、文件相对排序、原版定义不被覆盖增加回归检查。
- 画面对照优先覆盖儿童、驼背和丑陋，再按实际风险检查男女、衰老、身高／体型、畸形足、伤病及疤痕。逐项记录“用户确认／直接观察／仅静态／待测”，不把两个角色的成功外推为全部原版模型正常。
- 启动到主菜单不证明存档内显示。`genedatabase` 报错要区分私有 3D 类型与原版 human；私有网格缺少原版形变属性的日志，不能单独证明普通人物故障原因或修复效果。

## DNA 继承是另一条问题链

`set_ethnicity` 切换私有画像组可能影响子代继承；身份特质 `inherit_chance = 0` 不能隔离 ethnicity。移除占位 morph gene、修好儿童和特质外观，都不证明已实现“只换显示模型、保留角色包／二向箔遗传基线”。Fix 0.1.7 的 bridge 仍切换 ethnicity，纯显示方案尚未完成。

社区按文化随机重设子代 ethnicity 的回退不是原始 DNA 的准确恢复，不能用于满足保留 DNA 的要求。也不能仅删除 `set_ethnicity` 调用便宣称完成：现有显示路由依赖画像组，须另行验证替代显示机制、关闭 3D 回退和子代行为。
