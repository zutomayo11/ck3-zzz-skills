# Pack 模板迁移与隐藏层制作

新绝区零包以[角色包内置 绝区零绝区私有相机／正式模型包 契约](zzz-core-pack4-workflow.md)为模板。复用计算方法，角色资源由本人来源决定；不复制整包，不把旧包骨序、版本或安装命令当通用规范。

## 1. 固定来源和归属

记录模板、可见资源来源、现装 绝区零绝区私有相机 三份基线和哈希。候选路径不同不表示 entity、画像组或 GUI 不冲突。按白名单建立新包，不带入他人资源或空接口。

绝区零绝区私有相机 提供镜头/路由、活动隐藏别名、事件覆盖、GUI、菜单和诊断；Pack 提供本人实体、外观、隐藏 head/torso、同步动画及道具。身份/换装/3D 接口保持。引用闭包须在实际有效加载顺序下成立，不能只检查输入目录。

## 2. 隐藏层是动态契约

当前 hidden head 使用 36 槽基础布局及角色特有扩展，布局见共用规范；艾莲/爱芮额外手部节点按实际可见外观选择。逐角色解码骨序、父级、绑定与挂接来源，不把五骨参考的单位绑定强加到当前偏移上，不删除占位索引或道具轨道。小型 head 预加载，torso/可见附件保持原策略。

配对键为 **角色＋状态名＋重复序号 occurrence**。保留随机权重、身体/头部状态、帧数/帧率、entry/loop/exit、next_state 和入口可达闭包。缺本人 body clip 即失败，不能固定回 idle。

按实际父级和挂接矩阵生成隐藏节点；根已归一化时不重复消去。相机与道具分别验证，道具继承完整 T/Q/S。核对 accessory 引用、左右手/地面节点、坐骑及特殊形态；静置同名节点不能抢占动态节点。

可见外观共享本人 torso 姿势，各皮肤核对骨序、绑定和状态。保护导入骨架、蒙皮、身体动作、面部曲线、眨眼与贴图。外层尺度只用一次，不复制参考角色身高。

## 3. 绝区零绝区私有相机 接入与隔离

身份、画像组、能力与实际 3D 开关限定私有分支，不仅凭 trait 接入。事件按全部人物位解析有效相机；活动按相机/动作别名直接私有调用，同动作多机位保留不同别名。普通和未适配人物继续原调用。

共享画像组可能影响其他资源方案，selector 不能隔离所有公共 lookup；见[共享组检查](../../ck3-portrait-camera/references/shared-groups-and-entry-isolation.md)。新增组重新检查载入专用 default 和 human/anime 回退。未知结构、重复或覆盖冲突阻塞，不静默取第一个提供者。

## 4. 验证、封装与安装

1. 先查来源、角色/皮肤、命名、目标范围、定义/引用，再生成隐藏动画。
2. 逐状态与逐帧验证实际挂接，记录单位、容差、最大误差、时间范围、来源和算法哈希。变更使受影响缓存失效，不能刷新收据把失败变成功。
3. 相机参数和特殊构图保持；动作树逆变换核对原条件、顺序、随机候选和普通回退。菜单别名不混入活动隐藏别名。
4. 构图证据读取真实候选网格/动画/材质/相机，实际图审关键时点与外观。旧图复用保留原收据并单独证明有限采样等价；游戏未测仍 NOT_TESTED。
5. 封装后校验哈希。游戏/实际启动器关闭后事务安装，记录 journal 并完整回读；失败只回滚本次写入，保护外部变化、其他包和用户状态。
6. 用当前维护分派回读，历史 build/install/restore 不重跑。安装登记核对字节；后续只有格式变化可比较完整字段语义，不能忽略路径、版本、依赖或工坊 ID 差异。

## 5. 常见错误

| 错误 | 必要检查 |
|---|---|
| 同名状态被字典合并 | state＋occurrence、随机权重及 next_state |
| 只比 bind/idle | 可达状态与整段动态挂接 |
| 道具只复制平移 | 完整 T/Q/S 与实际 accessory 引用 |
| 凭五骨参考删节点 | 当前基础布局及角色扩展的解码、索引/绑定契约 |
| 同动作合成单一机位 | 原调用点的相机＋动作别名 |
| capability 被当作绝对隔离 | 公共画像组、节点 lookup 和有效覆盖 |
| 改名直接替换所有二进制 | 解析名称字段，独立验证其余字节 |
| 静态通过写成全部成功 | 对应版本/角色/外观/入口的用户实测 |

详细实现和报告索引只维护在共用规范，避免复制过期版本和计数。
