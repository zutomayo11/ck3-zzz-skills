# Carrier、骨骼与校准

先跟踪真实 `entity -> mesh -> skeleton -> animation -> attachment` 链；多个同名资源中不能随便取第一个。记录节点名称和索引、父子层级、绑定矩阵、动画采样、局部/世界坐标、`parent_joint`/`child_joint`、轴向/单位/旋转/缩放、所属 head/torso 载体以及身体/辅助头/道具动画的时间同步。

同名是接口约定，不证明索引或引擎取点相同。防止根变换重复、连接变换遗漏、局部偏移当世界偏移、绑定姿态与动画姿态混用。先定位调用、有效覆盖、节点加载与归属；确属参数问题才改当前用途的私有参数或隔离叶，不改公共根；相机偏移与节点偏移要记录变换顺序，避免重复补偿。

保护可见网格、真实身高、比例、蒙皮、表情、材质、导入骨序、层级和既有动画轨道。头颈方向与面部表情分开，只有确认是头颈同步问题才调用已有重定向流程。隐藏辅助网格仍需有效三角形、UV、包围盒和权重索引；节点名存在不足以证明资源有效。

皮肤、头饰、发型、鞋高和体态可能改变构图，按皮肤单独核查；不要污染默认皮肤或其他角色。相机定义和辅助节点发生变化时，使相关旧证据失效并重新测试。

项目历史 `pack2_camera_test` 资料显示，逐角色叶节点和 head/torso 所属载体曾影响前端结果；这是本项目候选的历史证据，不能推广成 CK3 通用机制。使用时以当前候选的 asset、骨序和实机结果为准。
