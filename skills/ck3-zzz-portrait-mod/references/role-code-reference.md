# 角色玩法参考的独立边界

本模块负责立绘、身份、调频/自选、音擎、角色创建、皮肤映射与双语。本轮先交付[五条3D资源核心链](../../ck3-zzz-3d-mod/references/code-reference.md)，没有复制角色生成器或生产角色清单。

## 后续提取的代码参考

| 算法来源 | 应提取的职责 |
|---|---|
| `build_mod.py` | 读取调用者数据、稳定ID、立绘材质/装配、人物模板与本地化生成函数 |
| `tuning_ui.py` | 选择、取消、收费时点、唯一性与冷却；费用和规则从调用者配置传入 |
| `wengines.py` | 音擎类型、装备条件、收益与专属适配的显式数据接口 |
| `agent_extensions.py`、`birth_rules.py` | 创建后的扩展和一次性迁移；保持旧档身份，不直接编辑存档 |
| `paper_carriers.py`、`role_gameplay.py` | 二维载体与原人物消隐/职责重写，实际依赖由调用者工程提供 |
| `english_localization.py`、`startup.py` | 双语与开局说明生成；不默认抓取网络资料 |

这些文件名是源码追溯点，不表示它们随技能提供。旧 `build_mod.py` 在导入时读本机配置、连接历史完整构建与退役保护；不能复制该入口作为通用角色制作器。应将读取、纯文本生成和输出分开，输入路径、角色数量、费用、皮肤顺序和依赖显式传入。

角色包独占人物创建和 `zzz_skin` 身份映射；独立前置只通过可选创建回调接入资源。五条3D链不能调用调频、添加身份特质或重新生成全部旧角色。

技能中的角色版本是历史快照。真实任务先读取使用者当前配置与来源；不得仅因技能记录某版本或模板数便覆盖更晚成品。本轮不包含玩法代码的可运行移植，不将五条3D测试当成玩法测试。
