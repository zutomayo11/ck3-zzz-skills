# 绝区零 CK3 角色包与内置 ZZZ Core

默认中文沟通。素材档案与生成工程分开维护，先定位数据再改生成器，不把整个生成目录当手工源码。

2026-10-09 快照为角色包1.1.5、内置Core来源0.6.2、正式Pack1–4 2.0.4／Pack5 1.0.3；20人35外观。以各工程settings、成品和现行安装收据为准。正式模型包依赖角色包；legacy 与 pack2-core-test 只用于另行选择的测试组合，测试仍需角色包。维护 ZZZ Core 或包边界时读[共用规范](../ck3-zzz-3d-mod/references/zzz-core-pack4-workflow.md)。保留开局提示、双语、调频和立绘功能；未观察的游戏表现仍为 `NOT_TESTED`，合并验证不能替代实机验收。

## 工作入口

- 素材与角色设计：`D:/CK3-mod/绝区零`。
- 生成工程：`D:/CK3-mod/zzz_mod_project`，先读其 `AGENTS.md` 和 `settings.json`。
- 实际输出：`settings.json.output_directory`（当前 `zenless_zone_zero`）；旧 `zenless_zone_zero_local` 仅留作回退，不再作正式运行/上传目录。

新增角色、皮肤、宝物，或核对姓名、姓氏、中间名时读 [数据与兼容规则](references/content-and-compatibility.md)；开局提示、英文/双语生成、构建、测试、工坊/本地登记问题读 [构建与登记](references/build-and-registration.md) 对应节。路径失效先搜索现有工程。现有清单和当次源数据优先于技能记录的历史数量。

纸片人黑模型、3D开关回退、代理人特性、音擎、混合调频和十连保底读 [纸片人消隐与调频](references/paper-rendering-and-tuning.md) 对应章节；只加载当前问题所需部分。

## 展示姿势、小头像与死亡

人物主面板、HUD、小头像、生活方式和地图人物标记是不同入口。姿势不一致时读[展示待机、静态头像与死亡](../ck3-zzz-3d-mod/references/portrait-display-and-death.md)：`default`只是回退，手选标志必须由实际请求类别读取；小头像保持静态取图，地图标记单独接入展示选择器。115死亡主面板使用显式死亡分支，实机尚未验收，死后换装变量报错另列待修。

角色包内置相机或模型接触问题按[当前共用规范](../ck3-zzz-3d-mod/references/zzz-core-pack4-workflow.md)与[取景/接触参考](../ck3-zzz-3d-mod/references/mount-contact-and-framing.md)分工处理，不通过角色数据或存档修改掩盖资源/调用错误。

## 执行方式

1. 从当前设置、短状态和 `build_manifest.json` 的必要字段定位目标，再按需查 `build_mod.py.load_data` 的角色ID、身份ID、档案路径、皮肤排序及引用；先保留备份，不读取完整历史日志或重复分析已验证模块。
2. 明确本轮改动文件，更新源 JSON 或对应生成器，保持稳定 ID 和旧档迁移逻辑。文案、数值属于 CK3 改编时如实标明；不为构建自动重抓网络资料。
3. 执行最小相关测试、生成和静态验证，检查透明 DDS、双语本地化、GUI和脚本引用。报告区别静态检查、规则模拟和实际 CK3 测试。
4. 功能升次版本，修复升补丁，每轮只改一次 `settings.json.version`。同步 descriptor、README、已登记的本地注册，保留工坊 ID；缓存只在启动器安全关闭后备份更新，运行中不并发改写，无法同步时明确记录延期。
5. 用户只授权制作/修复时完成本地可审核结果；不因此自动发布工坊、改订阅、改播放集或向他人发送消息。

有现成模板直接复用；测试只覆盖改动影响范围，命令成功只保留返回码、关键统计与输出路径，失败逐步提取必要上下文。技能更新不递增Mod版本。

续接复用最近短状态，不反复读完整历史；用户指定只看一次记录时不再回读。用户已要求不使用computer-use，优先已有脚本、日志及合规批量取证；缺实机证据就标明待用户测试，不另建UI helper绕过限制。

## 不可混淆的职责

角色包负责角色数据、纸片人立绘与消隐、身份/特性、音擎、调频、换装，以及内置 ZZZ Core 的共享镜头、分流、菜单与同步。模型工程负责可见模型、隐藏载体、骨架、动画、材质与道具。相机/同步问题可能需要修改角色工程 core_integration，不能再要求“涉及3D只改3D包”；专业算法仍读 3D/相机技能。按实际影响范围修改，保持角色 ID、zzz_skin 排序和已注册接口，不因兼容检查重建另一包。

本技能安装目录只保存流程和参考，不复制角色图片、游戏资源或私人存档。现有用户指示优先于本文历史习惯。
